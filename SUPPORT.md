# Support

Light the Candle is prerelease software offered on a best-effort basis. There
is no uptime, response-time, compatibility, or data-recovery SLA.

Use the canonical repository's
[Issues](https://github.com/FaultPilot/lightthecandle/issues) page for:

- installation and upgrade failures
- reproducible defects using synthetic data
- documentation problems
- feature proposals and beta feedback

Before filing an issue, include:

- Light the Candle version
- Codex or Claude Code version
- Python and Git versions
- operating system
- exact sanitized command and result
- whether the install came from a tag, branch, or local checkout

Remove credentials, personal information, client names, private repository
URLs, absolute home paths, and proprietary source excerpts from all reports.

Security issues follow `SECURITY.md` and must not be disclosed in a public
issue. Provider-account, billing, model, or host-agent problems belong with
the relevant provider.
