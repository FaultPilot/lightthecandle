# Roadmap

## Milestone 0.1: foundation

- Shareable Codex and Claude Code plugins around one portable CLI
- Cross-agent packaging contract with one manifest and local ledger per project
- Universal project manifest and four rigor profiles
- Executive strategy seed, outcomes, measures, assumptions, and constraints
- Stack, command, Git, CI, mobile, and provider discovery
- Preview-first `init` and `adopt`
- Preview-first local `register` for trusted copied manifests
- Read-only `status` and `doctor`
- Local event ledger with manifest binding and chain verification
- Multi-stack fixtures and safety tests

## Milestone 0.2: lifecycle and memory

- Requirements, decision, risk, plan, evidence, and memory schemas
- Strategy review, strategic-bet, portfolio-priority, and evolution-proposal
  schemas
- Lifecycle transition engine and explicit not-applicable rationale
- `lock`, `checkpoint`, `recover`, `review-strategy`, and `retro`
- Memory provenance, scope, confidence, freshness, and promotion rules
- Controlled propose, approve, trial, measure, retain-or-rollback evolution
- Exportable redacted handoff bundle

## Milestone 0.3: coordinated delivery

- Work graph, claims, leases, path/resource reservations, and conflict checks
- Worktree orchestration and safe parallel-agent assignment
- Exact-command verification receipts and change-bound approvals
- Whole-branch integration review

## Milestone 0.4: providers and policy

- GitHub and GitLab source/CI adapters
- Markdown, Obsidian, Linear, and Jira tracker adapters
- Web, mobile, API, library, and monorepo project packs
- Deployment, database, distribution, and observability interfaces
- Trusted, opt-in safety hooks

## Milestone 1.0: supported general availability

- Upgrade and rollback tooling
- Stable adapter SDK and conformance suite
- Signed versioned releases
- Private beta across unrelated real projects
- Install, adopt, recover, and release usability gates
- Published limitations, security model, and compatibility matrix
